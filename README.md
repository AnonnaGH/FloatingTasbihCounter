# Floating Tasbih Counter — V5 Beta

Android floating zikr/tasbih counter with a draggable overlay bubble that works over other apps.

## Features
- Tap main count or floating bubble to count
- Real-time synchronized main + floating count
- Draggable bubble with safe screen boundaries
- Messenger-style drag-to-remove target
- Target 33 / 100 / 500 / 1000 / Custom
- Vibration and sound on count
- Target-complete sound
- Bubble opacity control
- Unlock Durood Alert with two selectable Salawat options
- Durood alert volume control
- Light cream + gold Islamic-inspired UI
- Offline counter storage via SharedPreferences

## Durood choices
1. صلى الله عليه وسلم
2. اللهم صل وسلم على نبينا محمد

The unlock Durood feature uses the phone's Arabic Text-to-Speech engine.
